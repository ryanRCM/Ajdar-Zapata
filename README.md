# Ajdar Zapata

TV menu boards for the shop. Open a link on each TV and it plays full screen, nonstop. No login.

| TV | Shows |
|---|---|
| 1 | Sandwiches / Burgers / Hot Dogs, always on |
| 2 | Doner / Shawarma, then Starters / Sides / Drinks, switching every 20 seconds |

Live: https://claude.ai/artifact/DQufCywpypLtHh7m5geduP

On each TV, open the link once and tap **TV 1** or **TV 2**. The TV remembers, so the same link opens straight on its board from then on. (`#tv1` / `#tv2` on the end of the link skips the tap.)

- `site/`: the page and the three boards.
- `menu/`: the original menu designs (PDF).
- `HANDOFF.md`: where it stands and what's next (own account, a database for products and what's going on).
